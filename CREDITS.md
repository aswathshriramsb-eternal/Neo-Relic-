# CREDITS & ASSET STATEMENT — NEON RELIC: THE LAST SIGNAL

## Original Authorship & Zero-Dependency Statement

This game was developed as an original technical demonstration and temporary internship sample.

- **Source Code:** 100% original vanilla JavaScript, HTML5 Canvas, and CSS3 authored specifically for this project.
- **Audio & Sound Design:** 100% procedural sound synthesis in real-time using the native HTML5 Web Audio API (`AudioContext`, `OscillatorNode`, `GainNode`, `DynamicsCompressorNode`). Zero audio files, samples, loops, or sound banks were downloaded or bundled.
- **Visuals & Art:** 100% procedural 2D vector geometry drawn directly via Canvas 2D rendering contexts (`arc`, `rect`, `lineTo`, procedural hexagons, particle mathematics). Zero downloaded sprites, textures, or image files.
- **Typography:** Uses native standard system monospace font stacks (`'Courier New', Courier, monospace`). No external web fonts or downloaded font files.
- **Libraries & Frameworks:** Zero third-party dependencies, game engines (Phaser, Pixi, Unity), CSS frameworks, or runtime build steps.
- **Offline Self-Containment:** Runs completely offline via standard `file://` double-click in any modern browser.
